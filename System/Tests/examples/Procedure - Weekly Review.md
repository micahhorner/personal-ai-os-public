# Procedure — Weekly review

## Steps

1. Let the Steward run the weekly-maintenance workflow (or run `aios health` yourself).
2. Read the short review queue; decide the judgment calls.
3. Skim the change journal for the week.
4. Say aloud anything the week taught you — capture-tacit-context takes it from there.

## When to use / not use

Weekly. If it takes over 30 minutes, the system needs simplifying — that observation is itself worth capturing.
