# Setup Session Notes — 2026-07-10

## What this is

Record of the session in which this Personal AI OS was set up, kept as the founding example of an immutable source.

## Captured content

Discussed the reasons for adopting a portable, model-neutral system: owned context should outlive any single AI subscription; spoken context should be capturable; maintenance must not become a burden. Agreed to start with the generic core and personalize gradually through onboarding rather than restructuring up front. Considered using Obsidian alone without an operating layer; set that aside because retrieval and safe writes need rules, not just files.
