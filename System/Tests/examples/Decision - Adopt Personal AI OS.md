# Decision — Adopt Personal AI OS

## Decision

Run knowledge and AI work through this system's generic core; personalize progressively via onboarding.

## Why

Owned, portable context outlives any model subscription; safe AI writes require rules; spoken context deserves first-class capture.

## Alternatives considered

Plain Obsidian without an operating layer (tried, superseded — see [[Decision - Trial Obsidian Only]]); a hosted note app (rejected: not owned, not portable).

## Tacit context

See [[Tacit - Why Gradual Personalization - 2026-07-10]] — gradual structure is load-bearing for this user.
